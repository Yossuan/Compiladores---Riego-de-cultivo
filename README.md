### Guía de Ejecución 

Requisitos
 Tener PHP instalado (o usar XAMPP).

### Ejecución en Terminal
1. Abrir la terminal en la raíz del proyecto.
2. Ejecutar un programa correcto:
   `php index.php pruebas/correcto1.chc`
3. Ejecutar un programa con error léxico:
   `php index.php pruebas/error_lexico.chc`
4. Ejecutar todas las pruebas automatizadas:
   `php pruebas.php` (Genera el archivo `resultados_pruebas.txt`)

### Ejecución en Navegador (Opcional con XAMPP)
1. Copiar la carpeta del proyecto en `htdocs`.
2. Abrir en el navegador: `http://localhost/ChocoCode-Compiler/index.php`
